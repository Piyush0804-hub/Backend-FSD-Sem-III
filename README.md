## 🧠 What I'm Learning

This repository focuses on understanding how modern backend applications work behind the scenes.

### Core Concepts

```text
Client
   │
   ▼
Frontend
   │
   ▼
HTTP Request
   │
   ▼
Node.js + Express
   │
   ├── Routing
   ├── Middleware
   ├── Business Logic
   └── Authentication
   │
   ▼
Database
   │
   ▼
HTTP Response
   │
   ▼
Client
```

The objective is not only to learn syntax but also to understand **how different components communicate to build real-world applications**.
